# Репликация

## Настройка репликаций
После запуска сервисов необходимо выполнить инициализацию репликаций/
Скрипты инициализации выполняются по порядку. При выполнении скриптов есть таймаут на 30 секунд для того, чтобы предыдущий шаг инициализации успешно завершился

### Запуск сервисов
```bash
cd mongo-sharding-repl
docker compose up -d
```

### Инициализация
```bash
./scripts/init.sh
```

## Проверка количества документов по шардам

```bash
./scripts/test-document-count.sh
```
