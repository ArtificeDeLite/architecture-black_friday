# Шардирование

## Настройка шардирования
После запуска сервисов необходимо выполнить инициализацию шардирования/
Скрипты инициализации выполняются по порядку.

### Запуск сервисов
```bash
cd mongo-sharding
docker compose up -d
```

### Инициализация
```bash
./scripts/init.sh
```

## Проверка количества документов по шардам

```bash
./scripts/test-document-count.sh
```
